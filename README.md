# PDFPal

PDFPal is an AI-driven platform that enables interactive engagement with PDF documents. Users can ask questions, request summaries, and search for information using natural language processing. The application enhances document interaction, making it ideal for academic and professional use.

## 🚀 Features

- 🧠 **AI-Powered Document Interaction**: Engage with PDF documents using AI-driven queries.
- 📄 **Summarization**: Generate concise summaries of lengthy documents.
- 🔍 **Smart Search**: Find relevant information quickly using natural language.
- 🎨 **User-Friendly Interface**: A clean and intuitive UI built with Next.js and Tailwind CSS.
- 🔒 **Secure Transactions**: Integrated with Stripe for secure payments.

## 🛠 Technologies Used

- 🤖 **OpenAI**: Powers the AI-driven natural language processing.
- 🔗 **Langchain**: Enhances AI capabilities and document processing.
- ⚡ **Next.js**: Provides a fast and scalable front-end framework.
- 🎨 **Tailwind CSS**: Ensures a responsive and modern UI.
- 🏗 **TypeScript**: Adds type safety and improves code maintainability.
- 💳 **Stripe**: Handles secure payment processing.

## 📥 Installation

### Prerequisites
Ensure you have the following installed:

- 📌 Node.js (>=14.x)
- 📌 npm or yarn

### Steps

1. 📂 Clone the repository:
   ```sh
   git clone https://github.com/your-repo/pdfpal.git
   cd pdfpal
   ```
2. 📦 Install dependencies:
   ```sh
   npm install  # or yarn install
   ```
3. 🛠 Set up environment variables:
   - Create a `.env.local` file and add necessary API keys (OpenAI, Stripe, etc.).
4. 🚀 Start the development server:
   ```sh
   npm run dev  # or yarn dev
   ```

## 🏗 Usage

- 📤 Upload a PDF document.
- 💬 Use the interactive chat to ask questions or request summaries.
- 🔍 Search for specific content within the document.
- 💎 Upgrade to a premium plan for extended features via Stripe.
